# Система согласования документов

## Назначение
Веб-приложение для создания документов, направления их на согласование,
отслеживания статуса и оставления комментариев участниками процесса.

## Целевая аудитория
Сотрудники организаций, работающие с документооборотом: авторы документов,
согласующие (руководители отделов, директора) и администраторы системы.

## Предметная область
Документооборот внутри организации. Автор создаёт документ, назначает
согласующего и срок, после чего документ проходит этапы согласования.
Участники могут оставлять комментарии к документу на каждом этапе.

## Основные сущности
- Документ — создаваемый документ, требующий согласования
- Автор — сотрудник, создавший документ
- Согласование — процесс проверки документа согласующим
- Комментарий — текстовое примечание к документу или согласованию

## Основные функции
- Создание документа с указанием типа, автора и срока согласования
- Проверка возможности согласования (срок не истёк, документ готов)
- Добавление комментария к документу с указанием автора
- Назначение согласующего с учётом уровня полномочий
- Определение статуса согласования (срочное, стандартное, истёк срок)

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей с регистрацией и авторизацией;
- разработка REST API;
- контейнеризация приложения в Docker;
- настройка CI/CD.
