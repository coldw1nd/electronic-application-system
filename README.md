# Сервис электронных заявлений

Веб-приложение для просмотра электронных заявлений, их статусов, документов, комментариев и данных пользователей.

## Возможности

- просмотр заявлений и подробной информации по каждому из них;
- просмотр пользователей и связанных с ними заявлений;
- просмотр документов и комментариев;
- навигация между разделами сервиса;
- отображение страницы 404 для отсутствующих записей.

## Технологии

Python, Django 5.2, Django Template Language, HTML, CSS, JavaScript, SVG, JSON, pytest, flake8.

## Страницы

| Адрес | Описание |
| --- | --- |
| `/` | Главная страница |
| `/applications/` | Список заявлений |
| `/applications/1/` | Карточка заявления |
| `/users/` | Список пользователей |
| `/users/1/` | Карточка пользователя |
| `/documents/` | Список документов |

Число `1` в примерах — идентификатор записи из демонстрационных данных.

## Структура проекта

- `config/` — настройки Django и корневые маршруты;
- `homepage/`, `applications/`, `users/`, `documents/` — представления, маршруты и шаблоны разделов;
- `templates/base.html` — базовый шаблон сайта;
- `templates/includes/` — общие фрагменты шаблонов;
- `homepage/static/homepage/` — CSS, JavaScript и SVG-графика;
- `models/` — классы предметной области;
- `services.py` — операции над данными;
- `storage.py` и `data/` — чтение и хранение JSON-данных;
- `tests/` — автоматические тесты.

Страницы используют наследование шаблонов (`extends`, `block`), подключаемые фрагменты (`include`), контекст, циклы, условия и фильтры Django. Ссылки формируются через именованные URL с пространствами имён.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`.

## Проверка

```powershell
python manage.py check
pytest -v
flake8 . --extend-exclude=.venv,venv,env
```

Данные хранятся в JSON-файлах. Django ORM, регистрация пользователей и формы создания или редактирования записей пока не реализованы.
