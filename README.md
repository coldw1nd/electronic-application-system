# Сервис электронных заявлений

Веб-приложение для просмотра электронных заявлений и связанных с ними пользователей, статусов, документов и комментариев.

## Возможности

- просмотр списка заявлений и карточки отдельного заявления;
- просмотр пользователей и связанных с ними заявлений;
- просмотр документов с указанием связанного заявления;
- отображение статусов и комментариев;
- обработка запросов к несуществующим страницам.

## Технологии

Python, Django 5.2, HTML, Bootstrap 5.3, JSON, pytest, flake8.

## Страницы

| Адрес | Описание |
| --- | --- |
| `/` | Главная страница |
| `/applications/` | Список заявлений |
| `/applications/1/` | Карточка заявления |
| `/users/` | Список пользователей |
| `/users/1/` | Карточка пользователя |
| `/documents/` | Список документов |

Число `1` в примерах — идентификатор записи из демонстрационных данных.

## Структура проекта

- `config/` — настройки Django и корневые маршруты;
- `homepage/`, `applications/`, `users/`, `documents/` — обработчики страниц и маршруты разделов;
- `models/` — классы предметной области;
- `services.py` — операции над данными;
- `storage.py` и `data/` — чтение и хранение JSON-данных;
- `tests/` — автоматические тесты;
- `manage.py` — управление Django-проектом;
- `main.py` — консольный интерфейс.

HTML-страницы формируются в представлениях Django. Общий каркас страницы вынесен во вспомогательную функцию.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`.

## Проверка

```powershell
python manage.py check
pytest -v
flake8 . --extend-exclude=.venv,venv,env
```

Данные приложения хранятся в JSON-файлах. Django ORM и формы для создания или изменения записей в веб-интерфейсе не используются.
