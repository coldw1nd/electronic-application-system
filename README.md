# Система согласования документов

## Назначение
Консольное приложение для создания документов, направления их на согласование,
отслеживания статуса и оставления комментариев участниками процесса.

## Целевая аудитория
Сотрудники организаций, работающие с документооборотом: авторы документов,
согласующие и администраторы системы.

## Предметная область
Документооборот внутри организации. Автор создаёт документ, назначает
согласующего и срок, после чего документ проходит этапы согласования.
Участники могут оставлять комментарии к документу на каждом этапе.

## Основные сущности
- Документ — создаваемый документ, требующий согласования;
- Автор — сотрудник, создавший документ;
- Согласование — процесс проверки документа согласующим;
- Комментарий — текстовое примечание к документу.

## Возможности на этапе ПР2
- просмотр списка документов;
- добавление документа;
- поиск документа по названию и автору;
- сортировка документов по названию;
- назначение согласующего с проверкой уровня полномочий;
- согласование документа с проверкой срока и готовности;
- определение статуса согласования;
- добавление комментариев;
- хранение данных в JSON-файлах;
- обработка некорректного ввода пользователя;
- автоматизированные тесты.

## Структура проекта
- main.py — точка запуска и меню приложения;
- documents.py — функции работы с документами;
- approvals.py — функции работы с согласованиями;
- comments.py — функции работы с комментариями;
- storage.py — загрузка и сохранение данных;
- utils.py — вспомогательные функции ввода;
- data/ — JSON-файлы с данными;
- tests/ — автоматизированные тесты.

## Формат хранения данных
Данные хранятся в JSON-файлах в виде списков словарей:
- data/documents.json — документы;
- data/approvals.json — согласования;
- data/comments.json — комментарии.

## Требования
- Python 3.x;
- pytest;
- flake8.

```bash
pip install -r requirements.txt
```
